# TRU Movilidad Urbana — landing de Google Ads

Landing de una sola página creada para convertir tráfico de Google Ads en consultas por WhatsApp.

## Alcance

- Hero con propuesta y CTA principal.
- Catálogo visual con consultas contextuales por categoría.
- Presentación del negocio y cuatro puntos de venta.
- Formulario que prepara una conversación de WhatsApp sin almacenar datos.
- Metadata SEO, Open Graph, favicon, manifest y robots.
- Diseño responsive para mobile, tablet y desktop.

## Desarrollo local

1. Instalar dependencias con `npm install`.
2. Ejecutar `npm run dev`.
3. Validar tipos con `npm run typecheck`.
4. Crear la versión de producción con `npm run build`.

## Antes de publicar

- Crear y aprobar el preview de Vercel.
- Confirmar horarios, condiciones comerciales, stock y cualquier precio que se quiera incorporar.
- Configurar dominio, sitemap, URL absoluta de Open Graph, Google Ads y analítica.
- Probar WhatsApp y el formulario desde el dominio definitivo.
